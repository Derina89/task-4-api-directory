# Task 4 — API Directory

## Project Overview
This project is part of the SAN Web Technology Full-Stack Development Internship.

The API Directory project demonstrates how to work with REST APIs and display data from an API in a web interface.

## Features
- Fetches data from an API.
- Displays API data in a user-friendly interface.
- Uses JavaScript to handle API requests and responses.
- Provides a structured layout for viewing the retrieved data.
- Includes error handling for API request failures.
- Responsive design for different screen sizes.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- REST API
- Fetch API

## How to Run the Project
1. Clone or download this repository.
2. Open the project folder.
3. Open the main HTML file in your browser.
4. Use the interface to view the API data.

## Learning Outcomes
- Understanding REST APIs.
- Making API requests using JavaScript.
- Working with asynchronous operations.
- Handling API responses and errors.
- Displaying dynamic data on a web page.
